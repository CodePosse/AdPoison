Private DNS that bites back

Every app on every device looks up domain names before it connects. Swap your internet provider's DNS for one that refuses to answer for ad and tracker domains, and they vanish everywhere, even inside apps.

Our picks

All of these encrypt your lookups (DNS-over-HTTPS / DNS-over-TLS), so your internet provider can't read or sell your browsing history. Addresses change occasionally: confirm on the provider's site before setting up.

Set it up

Start with your phone (biggest app-tracking surface), then your router to cover the whole house.

Android 9+
  1. Open Settings → Network & internet (or Connections → More connection settings on Samsung).
  2. Tap Private DNS.
  3. Choose Private DNS provider hostname and enter a hostname from the table, e.g. dns.adguard-dns.com.
  4. Save. It applies on Wi-Fi and mobile data, system-wide.
iPhone & iPad

iOS uses configuration profiles for encrypted DNS.

  1. In Safari, open your provider's setup page (AdGuard, NextDNS, Control D and Mullvad all publish one) and download the profile.
  2. Go to Settings → General → VPN & Device Management, tap the downloaded profile and install it.
  3. Confirm under Settings → General → VPN & Device Management → DNS.
Windows 11
  1. Settings → Network & internet → select Wi-Fi or Ethernet → your connection, or Hardware properties.
  2. Next to DNS server assignment, choose Edit → Manual, enable IPv4.
  3. Enter the provider's IPv4 addresses and set DNS over HTTPS to On (automatic template) where offered.

AdGuard DNS IPv4: 94.140.14.14 and 94.140.15.15.

macOS

Install the provider's configuration profile (same as iPhone) for encrypted DNS, or set plain servers in System Settings → Network → your connection → Details → DNS.

Just the browser (Chrome, Edge, Firefox)
  • Chrome / Edge / Brave: Settings → Privacy and security → Security → Use secure DNS → choose Custom and paste a DoH URL such as https://dns.adguard-dns.com/dns-query.
  • Firefox: Settings → Privacy & Security → DNS over HTTPS → Max Protection → Custom.
Router (whole household)

Log in to your router (often 192.168.0.1 or 192.168.1.1), find DNS under WAN, Internet or DHCP settings, and replace the automatic servers with your provider's IPv4 addresses. Every device that joins your Wi-Fi, including smart TVs and consoles, is now filtered. For the most control, point the router at a Pi-hole on your network.

After switching: flush your DNS cache so old answers don't linger. Commands are on the hosts page.
