Hosts file blocker

Your computer checks its hosts file before asking the internet where a domain lives. Point tracker domains at 0.0.0.0 and they simply never load, in every browser and app.

Tick the groups you want. Entries tagged may break can stop something visible from working; the note says what.

2. Add it to your hosts file

Copy the block above first. These one-liners append your clipboard to the hosts file, so they never wipe what's already there.

Windows 10 / 11

Right-click Start, choose Terminal (Admin) or Windows PowerShell (Admin), then paste:

PowerShell (Admin)
Copy-Item "$env:windir\System32\drivers\etc\hosts" "$env:windir\System32\drivers\etc\hosts.bak"
Add-Content -Path "$env:windir\System32\drivers\etc\hosts" -Value (Get-Clipboard -Raw)
ipconfig /flushdns

Prefer clicking? Open Notepad as administrator, use File → Open, paste C:\Windows\System32\drivers\etc\hosts into the file name box (set the filter to All files), paste your block at the end and save.

Microsoft Defender may flag a modified hosts file as SettingsModifier. That alert is about entries blocking Microsoft's own domains; the Ad Poison groups don't include those. Review the alert and allow it if the only changes are yours.

macOS

Open Terminal and paste (you'll be asked for your password):

Terminal
sudo cp /etc/hosts /etc/hosts.bak
pbpaste | sudo tee -a /etc/hosts > /dev/null
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
Linux

Use wl-paste on Wayland or xclip -o -selection clipboard on X11:

Shell
sudo cp /etc/hosts /etc/hosts.bak
wl-paste | sudo tee -a /etc/hosts > /dev/null
# systemd-resolved (Ubuntu, Fedora, Arch...)
resolvectl flush-caches

Or save the downloaded file and run cat adpoison-hosts.txt | sudo tee -a /etc/hosts.

Android & iPhone

Phones don't let you edit the hosts file without rooting or jailbreaking. Use a filtering Private DNS instead. It does the same job, with wildcard support, across every app.

3. Flush DNS everywhere

Your OS and browser cache old lookups. Flushing makes the new block take effect immediately (and clears traces of where you've been, a small bonus).

Flush DNS commands
WhereCommand or pageCopy
Windowsipconfig /flushdns
macOSsudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
Linux (systemd)resolvectl flush-caches
Chrome / Edge / BraveOpen chrome://net-internals/#dns → Clear host cache, then chrome://net-internals/#sockets → Flush socket pools
FirefoxOpen about:networking#dns → Clear DNS Cache

Browser internal pages can't be opened by a link for security reasons: copy the address and paste it into the address bar.

Undo

Open the hosts file again and delete everything from # >>> Ad Poison hosts block >>> to # <<< Ad Poison hosts block <<<, or restore the hosts.bak backup the commands created. Then flush DNS.
